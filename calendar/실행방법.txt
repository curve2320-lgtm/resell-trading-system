■ 발매달력 사이트 — 컴퓨터에서 실행하는 방법 (Windows)

1. 이 압축을 원하는 위치에 풉니다. (예: C:\Users\1\Downloads\발매달력사이트)

2. PowerShell을 열고 폴더로 이동합니다.
   cd C:\Users\1\Downloads\발매달력사이트

3. 처음 한 번만: 필요한 부품 설치 (몇 분 걸립니다)
   npm install

4. 실행:
   npm run dev

5. 브라우저에서 접속:
   http://localhost:3000

   ※ 접속하는 순간 나이키·그랜드스테이지·뉴발란스·슈프라이즈 등
      전 출처 수집이 실제로 돕니다. 첫 화면은 몇 초 걸릴 수 있습니다.
   ※ 컴퓨터에서 실행 중일 때는 로그인 없이 '+ 일정 등록'도 사용 가능합니다.
      등록한 일정은 data\releases.json 파일에 저장됩니다.

6. 끄기: PowerShell 창에서 Ctrl + C


■ 참고

- npm 명령이 없다고 나오면 Node.js를 먼저 설치하세요: https://nodejs.org (LTS 버전)
- 이 폴더는 그 자체로 완성 실행본입니다. GPT로 만들던 원래 프로젝트 폴더가
  따로 있다면, 이 폴더의 app 폴더 안 파일들만 그쪽 app 폴더에 덮어써도 됩니다.
- 선택 환경변수: SOLDOUT_APP_KEY (솔드아웃 직접 연동), RELEASE_SOURCES_OFF (특정 출처 끄기)
  → 폴더에 .env.local 파일을 만들어 한 줄씩 적으면 됩니다. 없어도 잘 돌아갑니다.
